# Halal Cartoon Factory

একটি Flask ওয়েব অ্যাপ, যেটা একটি ছোট ইসলামিক গল্পের বিষয় (topic) থেকে
সম্পূর্ণ, একাধিক-দৃশ্যের (multi-scene) একটা কার্টুন `.mp4` ভিডিও বানিয়ে দেয় —
স্ক্রিপ্ট, ভয়েসওভার, দৃশ্যের ছবি, এবং একটা ফেস-সেফটি (face-safety) ধাপ —
সব কিছু ফ্রি-টায়ার টুল দিয়ে বানানো, কোনো ব্যাকগ্রাউন্ড মিউজিক ছাড়া।

## একটা রিকোয়েস্ট যেভাবে কাজ করে

```
topic + format  ->  01_script_generator   (Gemini: topic -> ৩টা দৃশ্য/scene)
                ->  02_prompt_modifier    (শরীয়াহ-সম্মত ফ্রেমিং + negative prompt যোগ করে)
                ->  03_voice_generator    (gTTS: ডায়ালগ -> scene_N.mp3)
                ->  04_visual_generator   (Hugging Face SD -> scene_N.png, টোকেন না
                                            থাকলে বা API কল ফেইল করলে লোকাল
                                            ফলব্যাক ছবি ব্যবহার হয়)
                ->  05_safety_filter      (MediaPipe + OpenCV: ছবি-মডেল ভুলে কোনো
                                            মুখ (face) বসিয়ে ফেললে সেটা ব্লার/মাস্ক করে)
                ->  06_video_renderer     (MoviePy: প্রতিটা ছবি তার নিজের অডিওর
                                            ঠিক সময় অনুযায়ী দেখানো হয়, তারপর
                                            জোড়া লাগিয়ে -> চূড়ান্ত .mp4)
```

প্রতিটা রিকোয়েস্ট `/assets`-এর ভেতরে নিজস্ব UUID জব-ফোল্ডার পায়, তাই একই
সময়ে দুইজন ভিডিও বানালেও কখনো একজনেরটা আরেকজনেরটার সাথে মিশে যায় না।

## সেটআপ

```bash
# ১. প্রজেক্টটা ক্লোন/আনজিপ করে ভেতরে ঢুকুন
cd halal-cartoon-factory

# ২. ভার্চুয়াল এনভায়রনমেন্ট বানিয়ে অ্যাক্টিভেট করুন
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# ৩. ডিপেন্ডেন্সিগুলো ইনস্টল করুন
pip install -r requirements.txt

# ৪. সার্ভার চালু করুন
python backend_server/server.py
```

তারপর ব্রাউজারে **http://localhost:5000** খুলুন।

## ⭐ API কী কোথায় দেবেন (কোড/ফাইল এডিট করার দরকার নেই)

আগে API কী `.env` ফাইলে বসাতে হতো। এখন অ্যাপের ভেতরেই সরাসরি বসানো যায়:

1. অ্যাপ খুলে উপরে ডান দিকে 🔑 (key) আইকনে ক্লিক করুন — **API কী সেটিংস**
   প্যানেল খুলবে।
2. **Gemini API Key** বক্সে আপনার কী পেস্ট করুন (স্ক্রিপ্ট/গল্প লেখার জন্য
   লাগে — ফ্রি কী নেওয়ার লিংক প্যানেলেই দেওয়া আছে:
   https://aistudio.google.com/apikey)।
3. চাইলে **Hugging Face Token**-ও দিন (আসল AI-জেনারেটেড দৃশ্যের ছবির
   জন্য, ঐচ্ছিক — ফ্রি টোকেনের লিংক: https://huggingface.co/settings/tokens)।
4. **সেভ করুন** চাপুন। কী-টা শুধু আপনার এই ব্রাউজারে (localStorage) জমা
   থাকবে এবং প্রতিবার ভিডিও বানানোর সময় সার্ভারে পাঠানো হবে — কোনো ফাইলে
   লেখা থাকে না, কোনো কোড এডিট লাগে না।

কী না দিলেও অ্যাপ বন্ধ হয়ে যায় না — Gemini কী ছাড়া একটা সাধারণ ফলব্যাক
স্ক্রিপ্ট ব্যবহার হয়, আর Hugging Face টোকেন ছাড়া একটা সাধারণ প্লেসহোল্ডার
ছবি ব্যবহার হয়।

> টিপ: যদি নিজের সার্ভারেই একটা ডিফল্ট কী বসিয়ে রাখতে চান (যেমন, নিজের
> শুধু ব্যবহারের জন্য, যাতে প্রতিবার না দিলেও চলে), তাহলে পুরনো পদ্ধতিও
> এখনও কাজ করে — `.env.example` ফাইলটা কপি করে `.env` বানিয়ে তাতে
> `GEMINI_API_KEY` ও `HUGGINGFACE_API_TOKEN` বসিয়ে দিন। অ্যাপের বক্সে
> দেওয়া কী সবসময় `.env`-এর কী-কে override করবে।

## ফোন থেকে ব্যবহার করা

অ্যাপটা যেমন আছে তেমনই ফোন থেকে চালানো যায় — এর জন্য কোনো পরিবর্তনের দরকার
নেই, কারণ সার্ভার আগে থেকেই `0.0.0.0`-তে চলে (শুধু নিজের কম্পিউটারে না,
পুরো লোকাল নেটওয়ার্কে পাওয়া যায়)। পদ্ধতি:

1. কম্পিউটার আর ফোন — দুটোই একই WiFi নেটওয়ার্কে থাকতে হবে।
2. কম্পিউটারে সার্ভার চালু রাখুন (`python backend_server/server.py`)।
3. কম্পিউটারের লোকাল IP বের করুন:
   - Windows: `ipconfig` (IPv4 Address)
   - Mac/Linux: `ifconfig` বা `ip addr` (সাধারণত `192.168.x.x`)
4. ফোনের ব্রাউজারে যান: `http://<ঐ-IP>:5000` (যেমন `http://192.168.0.105:5000`)।
5. ফোনে প্রথমবার ঢুকেই 🔑 আইকনে ক্লিক করে উপরের মতো নিজের API কী বসিয়ে
   সেভ করে নিন (প্রতিটা ব্রাউজার/ডিভাইসে আলাদা করে একবার বসাতে হবে)।

যদি ফোন থেকে পেজ না খোলে, কম্পিউটারের ফায়ারওয়াল পোর্ট ৫০০০ ব্লক করছে কিনা
দেখুন। ইন্টারফেসটা আগে থেকেই রেসপন্সিভ (মোবাইল স্ক্রিনে এমনিই মানানসই), তাই
ছোট স্ক্রিনেও ব্যবহার করতে সমস্যা হওয়ার কথা না।

## যা স্বয়ংক্রিয়ভাবে নিশ্চিত করা হয়

- **কোনো মুখ (face) থাকবে না, কখনোই।** প্রতিটা জেনারেট হওয়া ছবি দ্বিতীয়,
  স্বতন্ত্র একটা ফেস-ডিটেকশন ধাপ (`05_safety_filter.py`) পার হয়, যেটা
  প্রম্পটে যা-ই চাওয়া হোক না কেন, ছবি-মডেল বানানো যেকোনো মুখের অংশ ব্লার ও
  মাস্ক করে দেয়।
- **কোনো ব্যাকগ্রাউন্ড মিউজিক থাকবে না, কখনোই।** রেন্ডারার শুধু
  ভয়েসওভার ট্র্যাক মেশায় (চাইলে নিজের অ্যাম্বিয়েন্ট সাউন্ড, নিচে দেখুন)।
  মিউজিক যোগ করার মতো কোনো কোড-পথই অ্যাপে নেই।
- **ঐচ্ছিক অ্যাম্বিয়েন্ট সাউন্ড:** নিজের রয়্যালটি-ফ্রি `.mp3`/`.wav`
  ফাইল (বাতাস, পানি, পাখির ডাক ইত্যাদি) `assets/ambient/` ফোল্ডারে রাখুন।
  ফোল্ডারে ফাইল থাকলে প্রতিবার রেন্ডারে একটা আস্তে করে ন্যারেশনের নিচে
  মেশানো হয়। খালি থাকলে (ডিফল্ট) ভিডিও সম্পূর্ণ ভয়েসওভার-নির্ভর — সবসময়
  নিরাপদ অপশন।

## ভালো জেনে রাখা দরকার

- `mediapipe` ডিপেন্ডেন্সিটা ঐচ্ছিক। আপনার প্ল্যাটফর্ম/পাইথন ভার্সনে
  ইনস্টল না হলে `requirements.txt` থেকে ঐ লাইনটা মুছে দিন — সেফটি ফিল্টার
  নিজে থেকেই বিল্ট-ইন OpenCV ডিটেক্টরে চলে যাবে, কোনো কোড বদলাতে হবে না।
- Hugging Face-এর ফ্রি ইনফারেন্স API কোল্ড স্টার্টে মডেল "জাগাতে"
  ১০–৩০ সেকেন্ড লাগতে পারে; `04_visual_generator.py` প্লেসহোল্ডারে যাওয়ার
  আগে নিজে থেকেই আবার চেষ্টা করে।
- `.env`-এ `FLASK_DEBUG=true` দিলে Flask-এর ডিবাগ/অটো-রিলোড মোড চালু হয়,
  শুধু লোকাল ডেভেলপমেন্টের জন্য; প্রোডাকশনের মতো যেকোনো ব্যবহারে এটা
  বাদ রাখুন (বা `false`)।
- Settings বক্সে দেওয়া API কী শুধু আপনার ব্রাউজারে থাকে (localStorage) —
  এই ডিভাইস/ব্রাউজার অন্য কারো সাথে শেয়ার করলে আপনার কী-ও শেয়ার হয়ে
  যাবে, তাই পাবলিক/শেয়ার করা কম্পিউটারে এটা ব্যবহারে সাবধান থাকুন।

## মূল ড্রাফট থেকে যা ঠিক করা হয়েছে

- **নতুন:** কোড/`.env` এডিট না করেই API কী বসানোর জন্য অ্যাপের ভেতরে
  (🔑 আইকনে) একটা Settings প্যানেল যোগ করা হয়েছে — `index.html`,
  `script.js`, `server.py`, এবং `01_script_generator.py` /
  `04_visual_generator.py`-তে per-request override সাপোর্ট যোগ করে।
- **নতুন:** ছোট স্ক্রিনে হেডার যেন ভেঙে না যায় তার জন্য সামান্য
  রেসপন্সিভ (mobile) CSS টুইক করা হয়েছে; বাকি লেআউট আগে থেকেই ফোন-বান্ধব
  ছিল বলে অপরিবর্তিত রাখা হয়েছে।
- `script.js` আগে `{ topic, aspect_ratio, language }` পাঠাচ্ছিল, কিন্তু
  শুধু `aspectRatio` (camelCase) ডিক্লেয়ার করা ছিল — `aspect_ratio`
  `undefined` হয়ে সাবমিটের সময় এরর দিত। `{ topic, aspect_ratio: aspectRatio,
  language }` হিসেবে স্পষ্টভাবে ম্যাপ করে ঠিক করা হয়েছে।
- `04_visual_generator.py`-এর Hugging Face URL মার্কডাউন লিংক সিনট্যাক্সে
  (`[https://...](https://...)`) মোড়ানো ছিল, যেটা পাইথনে বৈধ URL
  স্ট্রিং না — এখন এটা একটা সাদামাটা স্ট্রিং, সাথে মডেল কোল্ড-স্টার্টের
  জন্য retry এবং শরীয়াহ `negative_prompt`-এর সঠিক ব্যবহার যোগ করা হয়েছে।
- `google-generativeai` ২০২৫-১১-৩০ তারিখে end-of-life হয়ে গেছে এবং আজ
  ইম্পোর্ট করলেই deprecation warning দেয়; স্ক্রিপ্ট জেনারেটর এখন Google-এর
  বর্তমান unified SDK, `google-genai` ব্যবহার করে।
- `core_engine/__init__.py` আগে ছিলই না, তাই `server.py`-তে
  `from core_engine import ScriptGenerator, ...` সাথে সাথেই ফেইল করত —
  আর সংখ্যা দিয়ে শুরু ফাইলনেম (`01_script_generator.py`) সাধারণ `import`
  দিয়ে লোডও করা যায় না। একটা `__init__.py` যোগ করা হয়েছে যেটা প্রতিটা
  নম্বর-দেওয়া ফাইল `importlib` দিয়ে লোড করে তার ক্লাস re-export করে।
- সেফটি ফিল্টার `mp.solutions.face_detection` ব্যবহার করত, যেটা
  MediaPipe-এর পুরনো (legacy) API — deprecated, এবং আপনার ইনস্টল করা
  ভার্সনের উপর নির্ভর করে হয়তো আর নেইও। এখন বর্তমান MediaPipe **Tasks**
  API অনুযায়ী লেখা হয়েছে, মডেল প্রথম ব্যবহারে নিজে থেকেই ডাউনলোড হয়, এবং
  সবসময়-চালু একটা OpenCV পাস গ্যারান্টিড ফলব্যাক হিসেবে আছে।
- `server.py` এখন নিজের ইনপুট ভ্যালিডেট করে, প্রতিটা রিকোয়েস্টকে আলাদা
  জব-ফোল্ডারে আইসোলেট করে, `/api/health` এক্সপোজ করে, এবং (হার্ডকোড করা
  Flask ডিবাগ সার্ভারের বদলে) ডিফল্টভাবে `debug=False` ব্যবহার করে
  (`FLASK_DEBUG` দিয়ে ওভাররাইড করা যায়)।
